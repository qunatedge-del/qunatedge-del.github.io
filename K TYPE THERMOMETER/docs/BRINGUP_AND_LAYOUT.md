# 打樣前確認、PCB 佈局與上電測試

## 打樣前請確認

1. CH340N（SOP-8）與 XC6206（SOT-23，U3/U4）**腳位編號**：圖上是依記憶標示，請對照廠商 datasheet。
   （TP4054、USBLC6-2SC6 的腳位與 LTC4054 / ST datasheet 一致。）
2. SDIC：BOOT 極性與 ISP 流程、PGIA 增益與 Vref 的實際選項（規格書 v0.1 表 3 只給 Vref = AVDDR = 2.4 V 的雜訊數據）。
3. VBAT_SENSE（A6，約 0.3…0.9 V 對 ACM）是否落在 PGIA 的絕對輸入範圍內（規格書只說受電路結構限制）。
4. LCD 玻璃廠對 4COM、1/3 bias、VLCD ≈ 3.0 V 的可行性與段定義（PDF 第 3 頁）。
5. 電池規格（容量、是否帶保護板）→ 決定 R18（充電電流：2 kΩ=500 mA、4 kΩ=250 mA）。
6. 背光 LED 的 Vf/If → R29。

## PCB 佈局要點

- **RT1 貼在 J1–J4 的金屬端子正下方/旁邊**，與端子同一個銅皮熱塊；U3（LDO）、U1、背光遠離。端子附近不要走大電流。
- 22 MΩ / 5.1 MΩ 與 K+ 走線：短、周圍挖空或加 guard（接 ACM），阻焊要好，焊後清洗。
- 模擬地與數字地單點接（U1 的 VSS/AVSS/DVSS 下方同一塊地）；ACM（腳 10）的 0.1 µF 與 C12、C7 靠近晶片，走線不要經過數位線。
- C9、C10、C11、C12、C13、C14、C15 緊貼各自引腳；AVDDR/ACM 的電容回到 AVSS。
- 32.768 kHz 晶振靠近 U1 腳 27/28，下方不走線，C29/C30 依實際板子寄生電容微調。
- USB D+/D−：等長、阻抗約 90 Ω 差分、USBLC6 靠近 USB-C 插座；CC1/CC2 的 5.1 kΩ 靠插座。
- LCD 走線（COM/SEG）遠離 TC 類比輸入；J7 到玻璃的線盡量短。
- 板子外殼若為金屬，K 型插座與機殼之間要有絕緣。

## 上電測試（按順序）

| 步驟 | 檢查 | 預期 |
|---|---|---|
| 1 | 不插電池、插 USB-C | VBUS 5 V；U4 輸出 3.3 V；CH340N 在電腦出現 COM 埠 |
| 2 | 接電池（SW7 關）→ 充電 | TP4054 CHRG 腳低（充電中）；VBAT 上升；電流 ≈ 500 mA（R18 = 2 kΩ） |
| 3 | SW7 開 | VDD = 3.3 V；靜態電流無異常 |
| 4 | 量 AVDDR、ACM | AVDDR = 設定值（建議 3.0 V）；ACM ≈ 1.2 V |
| 5 | 熱電偶端子開路 | K+ 對 ACM ≈ +339 mV（AVDDR = 3.0 V）；韌體顯示 `OPEn` |
| 6 | 端子短路 | 讀值 ≈ 0 mV → 溫度 ≈ 冷端溫度 |
| 7 | 接 K 型校正器或精密 mV 源 | 40.000 mV 時對照；做增益/偏移校正 |
| 8 | 冰水點 | 0.0 °C ± 校正後誤差；驗證冷端補償 |
| 9 | LCD / 按鍵 / 蜂鳴器 | 全段點亮測試、5 鍵可喚醒 STOP |
| 10 | 網頁記錄器連線 | 連續記錄 1 小時，無遺漏（seq 連續）、CSV 正常 |
| 11 | 拔掉 USB、量休眠電流 | STOP 預期約 35–45 µA（MCU ≤ 25–30 µA + VBAT 分壓 4.5 µA + LDO 約 1–4 µA + TP4054 漏電）；若 > 100 µA 先查 TXD1 倒灌與 EEPROM |
